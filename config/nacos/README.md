- 地址：`http://127.0.0.1:8848/nacos`。
- 命名空间名称：`prod-Ninja`；ID：`e7aa1b7a-358b-418b-92c4-afcb85fb585e`。
- 配置Data ID：`global-prod.yaml`；Group：`DEFAULT_GROUP`；类型：`yaml`。
- 已通过Nacos接口创建，并回读核对与本机配置备份一致。

- 本机配置备份：`global-prod.local.yaml`，包含用户提供的连接凭据，已加入gitignore。
- MySQL：`127.0.0.1:3307`，库名`Ninja`，用户名`root`；Redis：`127.0.0.1:6379`，database 0。该配置不会自动建库或执行建表SQL。

全局配置集中存数据库、Redis、网关WS、内部WS、线程池、超时、去重保留及战斗参数。服务名、HTTP端口、实例ID和Nacos引导配置保留本地；不能把所有服务的`server.port`和`spring.application.name`写成一个全局值。多实例时按需使用服务专属配置或启动参数，避免固定WS端口冲突。修改端口时也要同步对应Nacos发现元数据；单纯修改全局监听端口不保证发现元数据跟随。

两张背景仅外观不同，当前共用相同战斗几何，不新增地图伤害、平台或地图表。背景不需要由服务端加载或参与像素碰撞。

| 项目 | 首版设定 |
|---|---|
| 客户端参考逻辑画布 | 1440×480，3:1 |
| 水平范围 | 0～1440；角色受击框不能越界 |
| 脚底地面线 | Y=400，Y向下 |
| 跳跃初速度 | -18像素/Tick |
| 重力 | 1.2像素/Tick² |
| 最大下落速度 | 18像素/Tick |
| 逻辑频率 | 30Hz，现有实现固定 |
| 当前角色身高 | 受击框120逻辑像素 |
| 初始脚底位置 | A=(360,400)，B=(1080,400)，沿用宽度25%/75%的现有出生逻辑 |

按现有“先加重力再移动”的离散更新，跳跃最高离地126像素、约1秒落地。风隐/岩牙现有移速分别为210/180逻辑像素每秒，未修改CSV技能距离和角色数值。参数是第一版联调手感，后续用实际角色动画调整。

上传原图为2172×724，与逻辑画布同比例。客户端将整张图缩放到1440×480时，脚底线Y=400对应原图约Y=603.3，处于前景平台上；客户端绘制角色时用脚底对齐。不同屏幕继续等比缩放，比例不符时留边，不能把屏幕分辨率直接当服务端世界尺寸。

1440×480是客户端绘图约定：服务端目前只使用宽度和地面线，不新增未被程序使用的`height-px`配置。两张背景可以先在客户端切换测试；若以后要求双方看到同一随机地图，再补地图ID选择与同步，当前未实现该功能。

正式对战保持`battle.mode: VERSUS`，两人入场开始。单人联调改为`TRAINING`后新建战场。普攻1101/2101已补齐，设置`basic-attack-skill-ids: "1101,2101"`。自然回蓝`mana-regen-amount: 5`、`mana-regen-interval-ticks: 30`，新建战场生效。

完成配置后依次启动Agent、Scene、AgentMgr、Login、Gateway。Nacos、MySQL和Redis需先启动。账号注册、入场、技能输入仍需客户端Protobuf链路联调。
